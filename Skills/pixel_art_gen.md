## Image Requirements
- Text : **None**
- Label : **None**
- Monster Name : **None**
- Image Size : Square
- Background Color : Gray background
- Table border: 1px
- Table border Color : Black
- Style :
    - Ultra-detailed miniature pixel art
    - Highly dense pixels (comparable to or 64-bit era)
    - Intricate textures within each icon
