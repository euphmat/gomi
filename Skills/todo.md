# バトル info 画面整理 + 新規タブ追加
- 実装に際して、以下を心がけて実装すること。
- 既存コードの流用
- バグを出さない
- 新規ファイルの作成も可能

## 1. 戦闘画面の info タブから、以下の表示を削除する
- 討伐数
- 捕獲率
- 伝説出現率
- 伝説捕獲率
- 未取得

## 2. 既存のタブのデザインをもっとコンパクトにし、右側に 2 つのタブを追加する。
- 既存タブ : [Skill] [Item] [Info]
- 新規タブ : [Pet] [Medal]

## 3. Pet タブ
### 概要
- info タブで表示しているモンスターに対して、現在の 捕獲率, 伝説出現率、伝説捕獲率情報を表示。
- また、対象のペットが仲間になっている場合は、餌やりも戦闘中に可能にする。

## 4. Medal タブ
### 概要
- info タブで表示しているモンスターに対して、現在のメダル情報を表示
- また、対象のモンスターに対して、戦闘中にメダルの鋳造、アップグレードを可能にする
