# do not read ai agent

Firebase を用いて、クラウドセーブに対応させてほしいです。

現在の想定プレイヤー人数は３にしかいません。

プランは Spark プランなので、大容量ではありません。

なので、自動セーブだと、プランが超過してしまう可能性がありますので、手動、または利用上限がオーバーしない程度の自動セーブに調整してほしいです。

セーブを利用するには、ユーザー登録 (メールアドレス、または Google アカウントなど) が必要にしてほしい。

したがって、現在のセーブデータのインポート、エクスポート機能は廃止の上、クラウドセーブを実装してほしいです。
