# JRPG Pixel Art Generator
Please generate the images listed below in a **4x4 grid** format.

## Image Requirements
- Text : **None**
- Image Size : Square
- Background Color : Gray background
- Table border: 1px
- Table border Color : Black
- Style :
    - Ultra-detailed miniature pixel art
    - Highly dense pixels (comparable to or 64-bit era)
    - Intricate textures within each icon

## List of Images to Generate (Monster Icon)

- メタリックスライム
- スライムメタルカイザー
- ゴールデンスライム
注意 : ドラゴンクエストやファイナルファンタジーなど、著作権があるモンスターのデザインは真似しない。
