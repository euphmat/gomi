# 新規職業の実装

## 新規職業 : ダンサー
転職ゴールド : 100000

## 画像
job_dancer.webp

## アクティブスキル (アニメーションはこだわること)
- ポイズン・サルサ: 毒を塗った武器で舞う。敵全体に x ダメージと確率 x で「毒」を付与する。
- ジャグリングダガー: ランダムな敵単体に微小ダメージを x (4 ~ 16) 回与える。
- 混乱のタランテラ: 敵全体に確率で「混乱」を付与する。
- カース・ステップ: 敵全体にランダムな状態異常を x の確率で x (1~3) つ付与する。

## パッシブスキル
- オープニング・アクト: ダンジョン潜入時、自動的に味方全体へ素早さを x 上昇バフを付与する。
- 華麗なる見切り : x % の確率で、敵の攻撃を回避するようになる
- エナジャイジング : ターン終了時、味方全体のMPが極微量 x 回復する。
