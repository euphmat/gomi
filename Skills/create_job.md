# 新規職業の実装

## 新規職業 : 魔法剣士
転職ゴールド : 200000
転職条件 : スライムの森のスライムを全て捕獲している (伝説のスライムを省く)

## 画像
job_slime_master.webp

## アクティブスキル (アニメーションはこだわること)
- スライム投げ ランダムなスライムを投げる (アニメーションは実際のスライムのモンスター画像を使用する) **スライムによって、効果が異なる**
- スライムハザード (MP消費大) 上空から、ランダムな敵に20体のスライムを落下させる魔法攻撃

## パッシブスキル
- スライムボディ : 常に自信が受ける被ダメージを x % カットする。
- スライムコア : HP が x % 以上の時、致命傷を受けるダメージを受けても HP が 1 残る。
- 粘着物質 : ターン開始時に、敵全体の SPD を x % ダウンさせる。
