# 新規職業の実装

## 新規職業 : 魔法剣士
転職ゴールド : 200000
転職条件 : ナイト JobLv 50 + メイジ JobLv 50

## 画像
job_magic_knight.webp

## アクティブスキル
- フレイムタン : 単体のモンスターに atk + matk 複合の炎攻撃を行う。
- アイスブランド : 単体のモンスターに atk + matk 複合の氷属性の攻撃をランダムなモンスター三体に行う。
- サンダースラッシュ : 単体のモンスターに atk + matk 複合の全体雷攻撃を行う。
(本スキル実装にあたって、def が高い相手にも、matk で攻撃を与えられるよう、ロジックの調整を行ってください。)

## パッシブスキル
- マイティーガード : パーティー全体の def / mede を x ターンの間、x % 強化する。
- ウェポンブレス : パーティー全体の atk / matk を x ターンの間、x % 強化する。
- MP 吸収 : 敵に通常攻撃を行った時、与ダメージの x % 分、自身のMPを回復する。
