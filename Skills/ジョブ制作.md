# 新規職業の実装

## 新規職業 : つぬきち
転職ゴールド : 1000000
転職条件 = プレイヤーの名前が "つぬきち" であること。
**注意** : 隠しジョブのため、条件を満たさないと、一覧には表示されない
**注意2** : 1 度でも転職すると、常に一覧に表示される。

## 概要
ニコニコ動画に現れた歌い手

## 画像
job_tsunukichi.webp

## アクティブスキル (アニメーションはこだわること)
- 3 ポイントシュート : 敵 1 体にバスケットボールを投げつける
- 逮捕する : 敵 1 体を麻痺状態にする
- うたう : 敵全体を眠らせる
- モンスター : 自身の HP と MP を x 回復する。

## パッシブスキル
- 歌ってみた : ターン終了時、味方の全員の HP を x % 回復する。
