# 新規職業の実装

## 新規職業 : パラディん
転職ゴールド : 500000
転職条件 = ナイト Lv50, ダンサー LV50

## 概要
体力が高く、体力を使って敵を攻撃する前衛職

## 画像
job_black_knight.webp

## アクティブスキル (アニメーションはこだわること)
- ブラッドセイバー : 自身の HP を x % 消費して、敵単体に強力な物理攻撃ダメージ
- シャドウランス : 自身の HP を x % 消費して、ランダムな敵に x 回 上空から槍を降らす攻撃 (物理)
- カースブレード : 自身の HP を x% 消費して、敵全体に ATK/DEF デバフ + 呪い付与
- ヘルゲート : 自身の HP を x% と MPを 消費して、全体魔法攻撃 (闇属性)

## パッシブスキル
- ドレイン血の渇望 : 通常攻撃時にHPを吸収
- 不死の意志 : 常に状態以上 "呪い" 状態になり、他の状態異常にかからない。
- 鬼神の力 : 自身の HP が 50% 以下のとき、ATK と MATK が x 倍になる。
